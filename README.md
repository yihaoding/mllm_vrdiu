# IJCAI 2025 Tutorial  
**Multimodal Large Language Models for Visually Rich Document Understanding (VRDU)**

📧 **Primary Contact**: Yihao Ding, University of Sydney ([yihao.ding@sydney.edu.au](mailto:yihao.ding@sydney.edu.au))

---

## 🧠 Overview

This tutorial explores how Multimodal Large Language Models (MLLMs) enhance Visually Rich Document Understanding (VRDU) in domains like business, law, and medicine. It features both lectures and hands-on labs covering tasks, benchmarks, frameworks, and real-world applications.

---

## 🗓️ Schedule (3.5 Hours)

| Section                          | Time     | Description                                       |
|----------------------------------|----------|---------------------------------------------------|
| **Intro to MLLM for VRDU**       | 20 mins  | Motivation & Background                           |
| **VRDU + MLLM Background**       | 60 mins  | Tasks, Benchmarks, Lab 1: Pretrained Frameworks   |
| **MLLM for VRDU**                | 85 mins  | Frameworks, Training, Inference, Dataset, Lab 2   |
| **Conclusion**                   | 10 mins  | Future Trends & Wrap-up                           |

---

## 📌 Topics Covered

- **VRDU Tasks**: Layout Analysis, Key Info Extraction, Document VQA
- **Benchmark Datasets**: FUNSD, DocVQA, CORD, Form-NLU
- **Deep Learning Models**: LayoutLM, SelfDoc, UDoc
- **MLLM Frameworks**: DocLLM, mPLUG-DocOwl, HRVDA
- **Techniques**: Frozen LLMs, Chain-of-Thought (CoT), In-context Learning
- **Hands-on Labs**: Pretrained and MLLM-based VRDU with Form-NLU dataset
